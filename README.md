# Calculadora-de-IMC
Fiz essa calculadora como treino de JavaScript, HTML e CSS


# 🚀 Funciona lidades
**Cálculo de IMC em Tempo Real**: Permite ao usuário inserir seu peso (kg) e altura (m) para descobrir instantaneamente seu IMC.

**Feedback Visual Dinâmico**: O cartão de resultado muda de cor (azul, verde, laranja ou vermelho) e exibe o status de saúde correspondente (Abaixo do peso, Peso normal, Sobrepeso ou Obesidade) com base no valor calculado.

**Régua de Classificação**: Apresenta uma barra com gradiente de cores acompanhada de um marcador deslizante que ilustra a posição do usuário na escala de IMC.

**Modal de Contato Especializado**: Inclui um formulário em formato popup para que os usuários possam solicitar contato de nutricionistas.

**Validação de Formulário**: O envio de contato conta com validações estritas feitas no lado do cliente (verifica preenchimento de e-mail, nome e exige um telefone válido com 10 a 11 dígitos).

# 🛠️ Tecnologias Utilizadas
**HTML5**: Estrutura da página, dividindo a aplicação em seções claras de conteúdo informativo e painéis interativos.

**CSS3**: Estilização baseada na fonte Poppins, utilizando CSS Grid e Flexbox para garantir um layout responsivo que se adapta a telas maiores, além de animações de transição suaves para os resultados e o popup.

**JavaScript**: Responsável por toda a lógica matemática, manipulação dinâmica do DOM, cálculo de porcentagem da posição do marcador visual e tratamento de eventos de cliques e inputs.
